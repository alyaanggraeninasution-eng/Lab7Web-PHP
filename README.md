Praktikum 7  Pemrograman Server Side PHP

1. Tujuan
Mempelajari dasar pemrograman PHP, penggunaan variabel, operator, kondisi, perulangan, function, array, serta metode GET dan POST.

2. Tools yang Digunakan
- XAMPP
- Visual Studio Code
- PHP
- Web Browser

3. Cara Menjalankan Program
1. Buka aplikasi XAMPP.
2. Aktifkan Apache.
3. Simpan folder proyek di dalam `C:\xampp\htdocs\`.
4. Buka browser.
5. Masukkan alamat `http://localhost/Lab7Web_PHP/`.
6. Untuk menjalankan latihan lain, tambahkan nama file PHP pada alamat URL.

4. Struktur Folder
- `index.php` – Latihan 1: Menjalankan PHP.
- `latihan2.php` – Variabel, operator, dan kondisi.
- `latihan3.php` – Array dan foreach.
- `latihan4.php` – Function.
- `latihan5.php` – Form GET.
- `latihan6.php` – Form POST.
- `latihan7.php` – Pengolahan data sederhana.
- `mini_project.php` – Form data mahasiswa.
- `eksperimen1.php` – Menghitung rata-rata nilai.
- `eksperimen2.php` – Pencarian nama menggunakan GET.
- `eksperimen3.php` – Format harga Rupiah.
- `eksperimen4.php` – Validasi NIM.
- `eksperimen5.php` – Tombol Reset.
- `jawaban_evaluasi.txt` – Jawaban soal evaluasi.

5. Kesimpulan
Praktikum ini membantu memahami dasar pemrograman PHP dan pengolahan data pada sisi server. Program dijalankan menggunakan XAMPP dan diuji melalui browser.
